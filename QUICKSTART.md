### 🎯 How to Use

#### Step 1: Access the Application
Open your browser and go to:
```
http://localhost:3000
```

#### Step 2: Login
- **Username**: `tourist` (or any username)
- **Password**: `safe123` (or any password)
- Click "Login"

#### Step 3: Choose a Service

**Option 1: GPS Tracker 📍**
1. Click "GPS Tracker" on dashboard
2. Click "Get My Current Location" (auto-detects)
3. Fill in your details
4. Click "Start Tracking"
5. Watch your location update in real-time

**Option 2: Emergency Route Finder 🚨**
1. Click "Emergency Route Finder" on dashboard
2. Your current location is auto-detected
3. Enter destination (e.g., "Times Square" or "40.758,-73.985")
4. Click "Show Safe Route & Services"
5. See route with nearby police/hospitals

**Option 3: Police & Medical Finder 🏥**
1. Click "Police & Medical Finder" on dashboard
2. Click "Find My Location & Show All Services"
3. View all nearby emergency services
4. Filter by Police or Hospitals if needed

**Option 4: Live Tracking Map 🗺️**
1. Click "Live Tracking Map" on dashboard
2. View all active trackers
3. See real-time updates (demo data included)

### 🔧 Server Commands

**Start the server:**
```bash
npm start
```

**Stop the server:**
Press `Ctrl+C` in the terminal

**Restart for development:**
```bash
npm run dev
```
